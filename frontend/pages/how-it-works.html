ProofDrop / How it works

What "sealed" actually means

No account, no cloud storage, no trusting ProofDrop's word for it. Here's what happens at each step, and why it holds up.

STEP 01 / DROP

The file is fingerprinted, not uploaded

When you drop a file into ProofDrop, it's hashed right there in your browser using SHA-256 — a one-way function that turns any file into a fixed, unique string of characters. Change a single pixel or comma in the file and the fingerprint comes out completely different.

  • The file itself never leaves your device — only the fingerprint is sent onward.
  • There's nothing for ProofDrop to store, leak, or be subpoenaed for, because we never had the file.
  • You can re-run the hash yourself with any standard tool and confirm it matches.
STEP 02 / SEAL

The fingerprint is timestamped in public

The fingerprint is submitted to a public, append-only anchor — not a private ProofDrop database. That's the part that makes the proof independent: the record of "this fingerprint existed at this time" lives somewhere no single party, including us, can quietly edit.

  • Anchors are things like public timestamp authorities or transparency logs, chosen for how hard they are to rewrite after the fact.
  • Sealing can take a little time to fully confirm — you'll see a proof move from "pending" to "sealed" as the anchor finalizes it.
  • Once sealed, the timestamp is fixed. Backdating or altering it would require rewriting the public anchor itself.
STEP 03 / VERIFY

Anyone can check it, without asking us

Verification takes the original file and its proof record, recomputes the fingerprint locally, and checks that fingerprint against the public anchor. If both match, the file provably existed in that exact form at that exact time.

  • Verification doesn't require a ProofDrop account, and doesn't require ProofDrop to be online.
  • A proof record is a small, portable file — attach it to an email, hand it to a court, store it next to the original.
  • If even one byte of the file has changed since sealing, the fingerprints won't match and verification will say so plainly.
