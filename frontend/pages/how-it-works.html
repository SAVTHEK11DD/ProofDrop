How ProofDrop works

A file authenticity flow built from local hashing, MetaMask, ethers.js, and a Solidity contract.

+ New Proof
1

Hash locally

The browser reads the selected file and calculates a SHA-256 fingerprint. The file itself is never uploaded.

2

Record on-chain

MetaMask signs a Sepolia transaction that stores the fingerprint in the ProofDrop smart contract.

3

Verify anytime

ProofDrop hashes the file again and checks whether that exact fingerprint exists on-chain.

What ProofDrop stores

File hash
A `bytes32` SHA-256 fingerprint.
Sealer
The wallet address that recorded the proof.
Timestamp
The block timestamp from the Sepolia transaction.
File contents
Never stored, uploaded, or placed on-chain.
