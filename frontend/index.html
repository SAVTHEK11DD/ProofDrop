THE PROCESS

Three steps, in order — because each one depends on the last.

Sealing is sequential: you can't timestamp a fingerprint before it exists, and you can't verify a seal before it's anchored.

STEP 01 / DROP

Drop the file

Your file is fingerprinted right in the browser using a one-way hash. The file itself is never uploaded or stored anywhere.

STEP 02 / SEAL

Seal the fingerprint

The fingerprint is timestamped against a public, append-only anchor — not a database only ProofDrop controls.

STEP 03 / VERIFY

Verify, anytime

Anyone with the file and the proof record can confirm both the match and the moment — offline, and without trusting us.

WHY IT HOLDS UP

Verification that doesn't need us

  • 01

    The file never leaves your device

    Hashing happens locally, so there's nothing sensitive for anyone to intercept or store.

  • 02

    The anchor is public

    The seal is checked against an anchor anyone can audit independently — not a ProofDrop database.

  • 03

    The proof record is portable

    Download it, print it, hand it to a court or a client. It verifies with or without ProofDrop online.
